## 📊 How the Score is Calculated

The overall score (out of 10.00) uses a custom weighted formula:

* **30%** – Overall Story
* **10%** – Jerry's Storyline
* **10%** – George's Storyline
* **10%** – Elaine's Storyline
* **10%** – Kramer's Storyline
* **10%** – Secondary Characters *(Newman, Frank Costanza, etc.)*
* **10%** – Significant Others *(Schmoopie, Man Hands, etc.)*
* **10%** – Single-Shot Characters *(The Soup Nazi, Bookman, etc.)*

$$\text{Final Score} = (0.30 \times \text{Story}) + 0.10 \times (\text{Jerry} + \text{George} + \text{Elaine} + \text{Kramer} + \text{Secondary} + \text{SO} + \text{SingleShot})$$

1. Create a free project on [Supabase](https://supabase.com).
2. Go to the **SQL Editor** and run:

```sql
create table reviews (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  username text not null,
  episode_title text not null,
  story_rating numeric,
  jerry_rating numeric,
  george_rating numeric,
  elaine_rating numeric,
  kramer_rating numeric,
  secondary_rating numeric,
  so_rating numeric,
  oneshot_rating numeric,
